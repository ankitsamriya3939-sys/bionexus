BioNexus Studio

Complete Technical Blueprint, Computational Biology Engines, & Backend Architecture

1. Executive Summary & Architecture

BioNexus Studio is an in-browser computational biology platform built with React 19, Vite 8, and Express 5. It performs heavy bioinformatic operations (BLAST, MSA, Phylogenetics, Primer Design) entirely client-side using JavaScript, paired with an Express proxy for NCBI Entrez APIs and local JSON file persistence.

High-Level Data Flow

  • Frontend: React 19 + Vite at http://localhost:5173.
  • Backend: Express 5 server at http://localhost:5000.
  • NCBI E-Utilities: Express server proxies esearch, esummary, and efetch with fallback to direct client-side Entrez if offline.
  • Global Pipeline: WorkspaceContext.jsx holds the active sequence, syncing to both localStorage and Express server/data/.

2. Deep Dive: The Bioinformatic Engines

A. NCBI E-Utilities Integration (src/utils/ncbiService.js)

NCBI exposes Entrez E-Utilities. Our integration uses a 3-step pipeline:

  1. esearch: Queries keywords (e.g., "TP53 human") and extracts a list of Unique Identifiers (UIDs).
  2. esummary: Takes UIDs and downloads document metadata (title, organism, sequence length).
  3. efetch: Streams the raw FASTA sequence with headers and residue characters.
GET https://eutils.ncbi.nlm.nih.gov/entrez/eutils/efetch.fcgi?db=nucleotide&id=NM_000546.6&rettype=fasta&retmode=text

B. Local BLAST Engine (src/utils/blastEngine.js)

Instead of queuing on remote NCBI servers, BioNexus executes an interactive local alignment algorithm in JavaScript:

  • Smith-Waterman Dynamic Programming: Builds an $(m+1) \times (n+1)$ matrix where negative scores are floored at 0 to isolate local alignments.
  • Scoring Scheme: Matches (+2 nt, +4 aa), Mismatches (-3 nt, -2 aa), Gaps (-5 nt, -3 aa).
  • Traceback: Starts from the maximum score in the matrix and steps back to 0, constructing the query, match symbols (|, .), and subject.
Bit Score (S') = (λ * S - ln(K)) / ln(2)
E-Value = K * m * n * e^(-λ * S)

Supported Programs: blastn, blastp, blastx (translated query), tblastn (translated subject), and tblastx (both translated).

C. Multiple Sequence Alignment (src/utils/alignmentEngine.js)

  • Needleman-Wunsch Global Alignment: Penalizes ends to guarantee end-to-end alignment between sequences.
  • Progressive Alignment: The first sequence acts as a reference seed. As additional sequences are aligned, gaps introduced into the reference are synchronously padded across all existing rows.
  • Consensus & Conservation: Calculates column-wise frequency to extract the consensus residue and percentage agreement.
  • Clustal Colors: Real-time color coding for nucleotides and amino acid biochemical groups.

D. Phylogenetic Tree Construction (src/utils/phyloEngine.js)

  • Jukes-Cantor Distance: Corrects for multiple substitutions at the same site:
    d = -0.75 * ln(1 - (4/3) * p)
  • Clustering: Supports both UPGMA (constant molecular clock) and Neighbor-Joining (variable lineage rates).
  • Newick & SVG: Serializes clusters into Newick parenthetical strings and calculates coordinates to render interactive SVG trees.

E. PCR Primer Designer (src/utils/primerEngine.js)

  • Thermodynamic Melting Temperature: Uses SantaLucia nearest-neighbor enthalpy and entropy values with monovalent salt adjustments.
  • GC Clamp: Enforces 1-2 G/C residues within the final 5 bases of the 3' end.
  • Dimer & Hairpin Check: Analyzes self-complementarity to screen out unwanted secondary structures.

F. 3D Protein Structure Viewer (src/components/ProteinStructure.jsx)

Integrates 3Dmol.js to mount a WebGL canvas that downloads PDB files from RCSB and renders Cartoon, Stick, Sphere, and Molecular Surface representations.

3. Express Backend (server/server.js)

  • CORS & Proxying: Forwards requests to NCBI with proper user-agent headers to avoid browser CORS blocks.
  • JSON File Persistence: Stores records in server/data/ (projects, sequences, primers, analyses) without requiring database installation.
  • Crash Guards: Catches uncaughtException and unhandledRejection so background network glitches never bring the server down.
  • Single-Port Production: Statically serves Vite's built dist/ bundle on port 5000 in production.

5. How to Add a New Tool Step-by-Step

  1. Write the Algorithm: Create a pure JavaScript module in src/utils/yourToolEngine.js.
  2. Build the Component: Create src/components/YourTool.jsx and access activeSequenceObj via useWorkspace().
  3. Add the Route: Register the path in App.jsx inside getTabFromPath() and getPathFromTab().
  4. Add Navigation: Insert a button and Lucide icon in Sidebar.jsx and Navbar.jsx.
